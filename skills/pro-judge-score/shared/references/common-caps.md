# 공통 상한 규칙

모든 대회에 기본 적용한다. 항목 점수가 상한보다 높으면 상한으로 내린다 (`aggregate.py`가 강제한다).

| id | 규칙 | 상한 | 예시 |
| --- | --- | --- | --- |
| `intent-not-evidence` | "~할 계획/예정/하면 된다"는 의도다. 근거가 아니다 | 5 | "향후 지자체와 협력할 예정" |
| `no-specifics` | 숫자·고유명사·관찰이 없는 주장 | 5 | "많은 사람이 불편을 겪는다" |
| `claim-not-verified` | 주장한 기능이 시연·배포에서 확인 안 됨 | 6 | 배포 주소가 죽어 있음, 데모 영상만 있음 |
| `claim-failed` | 주장한 기능이 확인 중 실패 | 4 | 로그인 버튼을 누르면 오류 |
| `quote-for-seven` | 7점 이상은 원문 인용이 있을 때만 | 6 | 인용 없이 8점을 주면 6점으로 내려간다 |
| `length-neutral` | 분량은 점수에 영향 없음 | - | 슬라이드 40장이 10장보다 유리하지 않다 |

## 쓰는 법
- 상한에 걸리면 `cap_applied`에 id를, `unlock_hint`에 "무엇이 원문에 있으면 넘는지"를 쓴다.
- 여러 상한에 걸리면 가장 낮은 것 하나를 적는다.
- 확인하지 못한 대상(죽은 URL 등)은 0점이 아니라 `claim-not-verified`다.
