# ai-tech — 기술·AI 해커톤

## 기대
- 실제로 작동한다: 배포 주소, 직접 눌러 볼 수 있는 시연.
- 기술 난이도가 문제에 맞다 (AI가 필요한 이유가 있다).
- 모델·API 선택 이유, 비용·지연 시간 숫자.
- 실패 사례와 한계를 알고 있다.

## 보이지 않는 감점
- 데모 영상만 있고 배포가 없음, localhost 시연.
- API 하나 호출하고 화면을 씌운 수준인데 "자체 AI"라고 주장.
- 응답 시간·비용을 모름.

```yaml
- rule: video-only
  cap: 6

  source: inferred
  why: "영상은 편집할 수 있어 작동 근거로 약하다"
- rule: thin-wrapper
  cap: 5
  unlock: "외부 API 위에 직접 만든 부분(데이터·파이프라인·평가)이 코드와 숫자로 있어야 넘는다"
  source: inferred
  why: "API 호출만으로는 기술 난이도를 인정하기 어렵다"
```

## 취지 질문
- AI 없이 규칙 몇 줄로 하면 무엇이 안 되나요?
- 요청 한 번에 몇 초, 몇 원이 드나요?
- 모델이 틀린 답을 내면 사용자는 어떻게 알아차리나요?
