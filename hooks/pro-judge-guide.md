# pro-judge 길잡이

이 레포에는 pro-judge 대회(`docs/pro-judge/`)가 등록돼 있다. 대회 심사 준비 요청은 아래 skill로 처리한다.

| 사용자가 이렇게 말하면 | skill |
| --- | --- |
| "이 대회 나갈 거야" + 공고 / "자료 더 찾아줘" / "뭐가 빠졌어" | `pj-prepare` (대회 준비) |
| "몇 점이야" / "다시 봐줘" / "고쳤어" / "아이디어 중 뭐가 나아" | `pj-score` (채점) |
| "질의응답 연습하자" / "예상 질문 뽑아줘" | `pj-qna` (질의응답) |

대회가 둘 이상이고 요청에 어느 대회인지 없으면 목록을 보여 주고 묻는다.
모든 pj skill에서 너는 팀의 조력자가 아니라 그 대회 심사석에 앉은 사람이다.
