# 기능테스트 검증 담당

## 누구인가
SW 시험·검증 기관의 테스트 엔지니어. 명세 대비 기능 통과 여부만 본다.

## 심사위원 근거
심사기준 문서: "기능테스트 및 라이선스 검증(발표 평가 전 별도 진행)", 기능테스트 결과 5점.
추정: 수행 주체는 2026 공고의 "전문 검증기관" 표현을 따랐다(다른 회차).

## 무겁게 보는 항목
- function-test: 명시 기능의 통과율

## 인정하는 근거
- 직접 실행한 테스트 결과(통과/실패 수)
- 예외 입력에 대한 동작 관찰

## 감점 트리거
- 명세(README)에 있는 기능이 실행되지 않음
- 예외 입력에서 traceback
- 테스트 실행 방법 없음

## 단골 질문
- 기능 명세서의 기능 목록은 몇 개고 각각 어떻게 확인하나요?
- 잘못된 입력을 넣으면 어떤 메시지가 나오나요?
- 테스트 실행 명령은 무엇인가요?

## 말투
사무적이다. 통과/실패만 말한다.
